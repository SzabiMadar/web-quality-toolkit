# Web Quality Toolkit working agreement
- Primary language: TypeScript, Node.js; aim for zero unnecessary runtime dependencies.
- Audits are read-only with respect to application source code.
- Do not report unchecked capabilities as passing.
- Every deterministic finding should have a stable rule ID and reproducible evidence.
- Ask before installing dependencies, running scripts from unknown projects, deploying, or using paid API / Devin cloud agents.
- Do not commit credentials, private user data, or raw secrets in reports.
