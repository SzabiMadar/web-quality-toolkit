# Consistent, client-ready report

## Scope
Date; domain/repository; market/languages; goal; audited URLs; evidence surfaces; tool versions actually run; sampling limits.

## Summary
Main verified risks and top fixes in 3–5 sentences. No invented health score.

## Coverage
| Category | Actual method/surface | Status | Limitation |
|---|---|---|---|
| Canonical | generated build or inspected HTML | passed/confirmed/not-tested | sample/build scope |
| Performance | Lighthouse/field if run | not-tested if absent | no measured CWV |

## Findings
| Priority | ID | URL/path | Observation & evidence | Status/severity | Fix | Retest |
|---|---|---|---|---|---|---|

For high-impact issues give observed/expected details, official justification and possible exceptions. Distinguish fact from hypothesis.

## Action plan
Group by proven blockers, shared template issues, content opportunities and optional improvements. Note owners/approvals where known and verification steps.

## Unknowns / next checks
List untested areas explicitly, why data/tools were unavailable and the minimal test to resolve each. Qualitative AEO/GEO readiness is **not actual citation/rank measurement**.
