# Consolidated audit report / remediation

Read ../../references/AUDIT_PROTOCOL.md and ../../references/REPORT_TEMPLATE.md.

1. Collect actual inspected page samples and named tools, relevant specialist observations, and optionally **real** findings.json/summary.md.
2. De-duplicate by root cause, preserve rule/URL evidence, and keep confirmed, needs-review, recommendation and not-tested **distinct**.
3. Prioritize proven blockers, shared-template defects, user-journey problems and editorial improvements; note approvals and risks.
4. Produce a short business-facing executive summary and precise technical appendix in the user's language.
5. For every item specify action, location, observed versus expected, proof, validation procedure, and owner where known.
6. Compare before/after only with two actual dated audits of compatible test conditions.
7. When no file-creation tool exists, deliver readable Markdown rather than pretending to create a PDF/HTML attachment.
8. Never guarantee Google rankings, AI citations, accessible WCAG compliance or rich-result eligibility.
