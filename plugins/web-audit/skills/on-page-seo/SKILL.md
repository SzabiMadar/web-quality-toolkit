# On-page SEO

Follow ../../references/AUDIT_PROTOCOL.md.

1. Select actual representative pages; distinguish source/HTML/live rendered output.
2. Verify the document title and meta description in the inspected page. Assess uniqueness, truthfulness, topic match and user value. Character counts are **not fixed ranking rules**.
3. Inspect meaningful H1–H6 hierarchy, semantic landmarks, page intent, visible service/product content and unambiguous next steps. Multiple H1 tags are not automatically a search penalty.
4. Identify duplicated generic metadata only across pages actually examined.
5. Separate suggestions from errors; an inaccessible head section means **not-tested**, not missing metadata.
6. Provide per-URL exact observed title/description/heading, proposed improvement where appropriate, reason and retest method. No invented rankings/search volumes.

Official references: https://developers.google.com/search/docs/appearance/title-link and https://developers.google.com/search/docs/appearance/snippet .
