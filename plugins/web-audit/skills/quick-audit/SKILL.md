# Quick website triage

Read ../../references/AUDIT_PROTOCOL.md. Select at most 3–5 real URLs representing the main site types; state exact scope.

1. Check actual accessible source/live evidence for discoverability, canonical, title/meta, prominent navigation, obvious accessibility issues and essential service answerability.
2. Only where trusted build/CLI is available and execution authorized, the independent CLI quick profile runs canonical alone; it does not inspect metadata, content or accessibility.
3. Record 3–7 **evidence-backed** highest-value findings with URL/path, observation and status; list unavailable checks and don't invent a score.
4. Recommend full-audit or one specialist skill only for material gaps. Do not silently start more agents, paid services or code fixes.
5. Summarize in the user's language with top priorities and retest action.
