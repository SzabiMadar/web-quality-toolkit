# AEO/GEO — qualitative content readiness

Read ../../references/AUDIT_PROTOCOL.md.

1. Establish audience, locality, language, user questions and actual inspected pages.
2. **Answerability:** identify exact passages that do or do not answer key questions with scope, constraints and next action.
3. **Entity consistency:** compare factual business/person/service/location names across visible pages. Don't invent authority claims, credentials or locations.
4. **Source quality:** flag unsupported factual assertions; prefer dated verifiable primary references and clear authorship where appropriate.
5. **Extractability:** confirm important descriptions are accessible in the actual HTML/rendered view where available; headings and self-contained paragraphs help readers too.
6. **Markup:** structured data may clarify entity identity; it does not guarantee generative visibility.
7. **Crawler access:** distinguish training versus discovery/search bots and verify provider-specific current documentation before advising.
8. **Measured citations:** only claim them if the user provides or tools retrieve real AI responses with engine, date and prompt. Otherwise explicitly label rankings, traffic and citations **not-tested**.
9. Produce URL-specific editorial changes and verification suggestions. Never invent a GEO score or promise AI inclusion.
